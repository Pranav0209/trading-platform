# Sprint 08 - Auth Service

This is the Authentication microservice built with NestJS.

## OpenAPI (Swagger) Documentation

The service automatically generates an OpenAPI document describing the available endpoints (register, login, refresh, me) using decorators on controllers and DTOs.

- **Human-readable Swagger UI**: `http://localhost:3000/docs`
- **JSON OpenAPI Document**: `http://localhost:3000/docs-json`

_(Note: Ensure the service is running locally to access these endpoints)._
